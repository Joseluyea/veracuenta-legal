# VeraCuenta — legal

Public legal documents for **VeraCuenta Uploader**, the personal tool that
uploads original narrated videos to the YouTube channel
[VeraCuenta](https://www.youtube.com/@VeraCuenta). They are published with
GitHub Pages at <https://joseluyea.github.io/veracuenta-legal/>.

YouTube:

- [Privacy Policy](https://joseluyea.github.io/veracuenta-legal/youtube-privacy.html)
- [Terms of Service](https://joseluyea.github.io/veracuenta-legal/youtube-terms.html)

`PRIVACY.md` and `TERMS.md` hold the same text and stay in place, because
their addresses were submitted with the YouTube API compliance audit.

Since September 2026 the tool also sends the channel's own videos to the
creator's [TikTok](https://www.tiktok.com/@veracuenta) inbox as drafts:

- [TikTok Privacy Policy](https://joseluyea.github.io/veracuenta-legal/tiktok-privacy.html)
- [TikTok Terms of Service](https://joseluyea.github.io/veracuenta-legal/tiktok-terms.html)
